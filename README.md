#  Fleet Booking App

A modern **Flutter-based Fleet Booking Application** designed to simplify vehicle fleet management and trip booking through a clean, intuitive mobile experience.

##  About the Project

**Fleet Booking App** is a mobile application built with Flutter to provide an organized experience for managing and booking fleet vehicles.

The application focuses on providing users with an easy way to:

*  Browse available vehicles
*  View and manage trips
*  Select suitable fleet vehicles
*  Track active trips
*  View vehicle and trip details
*  Manage booking-related information

The project is developed as part of the **DevHub P2A** team.

---

##  Features

###  Fleet Management

* View available vehicles
* Display vehicle details
* Vehicle type and specifications
* Seat capacity
* Powertrain information
* Transmission details
* Vehicle availability

###  Trip Management

* View upcoming trips
* View active trips
* Display trip details
* Track trip status
* Access booking information

###  Booking

* Browse available fleet vehicles
* Select a suitable vehicle
* View booking details
* Manage trip-related information

###  User Interface

* Clean and modern UI
* Responsive Flutter layouts
* Reusable widgets
* Consistent design system
* User-friendly navigation

##  Getting Started

### Prerequisites

Before running the project, make sure you have installed:

* [Flutter SDK](https://docs.flutter.dev/get-started/install)
* [Dart SDK](https://dart.dev/get-dart)
* Android Studio or Visual Studio Code
* Android Emulator or a physical device

You can verify your Flutter installation using:

```bash
flutter doctor
```

---

##  Installation

Clone the repository:

```bash
git clone https://github.com/DevHub-P2A/DevHub-Fleet-Booking-Flutter.git
```

Navigate to the project directory:

```bash
cd DevHub-Fleet-Booking-Flutter
```

Install dependencies:

```bash
flutter pub get
```

---

##  Run the Application

Connect an Android/iOS device or start an emulator, then run:

```bash
flutter run
```

To check available devices:

```bash
flutter devices
```

---

##  Testing

Run the project tests using:

```bash
flutter test
```
